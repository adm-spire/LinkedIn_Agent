LinkedIn Job Hunter is a local, autonomous job-search agent that runs on a schedule and turns LinkedIn's job feed into a single ranked email digest. It drives Playwright through the @playwright/mcp server with a bounded deepagents (LangChain middleware) agent to scrape job cards from accessibility snapshots, then deduplicates and fingerprints results, applies LLM-free rule and exclusion filters, and semantically scores each remaining job with DeepSeek against a user-defined profile using validated JSON output. New matches are persisted in SQLite with a repository pattern and a derived lifecycle state (NEW/SEEN/EMAILED/RETRY, no status column), including profile-hash-based re-scoring and failed-attempt caps, before being formatted into an HTML and plain-text digest delivered over SMTP. The system is engineered for safety and cost control: a typed guard layer enforces hard per-query and per-run budgets on LLM calls, tool calls, steps, tokens and wall-clock time, restricts the agent to an allowlisted set of browser tools and LinkedIn job URLs, treats all page content as untrusted to mitigate prompt injection, and halts on login walls or captchas with an email notification. Built in Python 3.12 with Pydantic-validated YAML configuration, secret isolation via environment variables, file-locking for cron-safe execution, structured logging, and a pytest unit-test suite.
